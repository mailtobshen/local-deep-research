**Export menu's "ODT (LibreOffice)" entry is now ".docx (Ms Office)".
** The backend was renamed from ``ODTExporter`` to ``DOCXExporter``
and re-targets Pandoc at ``-t docx`` instead of ``-t odt`` so the
downloadable artefact is a real Office Open XML document (Microsoft
Word, Google Docs, LibreOffice all open it natively).

The DOCX export now also matches the PDF path on the three behaviours
the user asked for:

* The "关于{query}的研究报告" title line is prepended before the
  table-of-contents heading (query is the original research question,
  not the edited title).
* The "第N页/共M页" page-number footer is centred at the bottom of
  every page in 宋体 9pt. Because Pandoc has no built-in switch for
  that exact format, the DOCX zip is post-processed to inject a
  ``word/footer1.xml`` with real OOXML ``PAGE`` / ``NUMPAGES`` field
  codes — Word/LibreOffice updates the numbers on open.
* The old "Generated by LDR..." attribution paragraph that used to
  live at the end of the report body is scrubbed (defence-in-depth
  regex) and not re-added.
* The rewritten local image routes (``/images/<research_id>/<filename>``
  after ``images.store.rewrite_markdown``) are resolved against the
  same Flask origin via Pandoc's ``--resource-path`` — parity with
  the PDF path's ``base_url`` handling.

The old ODT-specific entry points in ``ExportOptions`` / ``ExportResult``
/ ``research_routes`` / ``research_service`` were updated to the DOCX
key, and the "ODT (LibreOffice)" translation key was retained for
back-compat (new key added: ``.docx (Ms Office)``).
